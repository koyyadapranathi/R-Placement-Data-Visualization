# R Placement Data Visualization

## Week 2 Internship Task

This project focuses on data visualization and insight communication using R. The Student Placement Dataset was analyzed to understand placement outcomes, academic performance, work experience, specialization, salary distribution, and relationships between numerical variables.

## Objectives

- Analyze the Student Placement Dataset using R.
- Create meaningful visualizations.
- Analyze placement outcomes.
- Visualize academic performance distributions.
- Examine salary distribution.
- Analyze relationships between academic performance and salary.
- Create a correlation heatmap.
- Communicate important insights through graphs.

## Dataset

The project uses a Student Placement Dataset containing information about:

- Gender
- SSC percentage
- HSC percentage
- Degree percentage
- Employability test percentage
- MBA percentage
- Work experience
- MBA specialization
- Placement status
- Salary

## Technologies Used

- R
- RStudio
- ggplot2
- dplyr
- tidyr
- corrplot

## Visualizations

The project includes:

1. Placement Status Distribution
2. Placement Status by Gender
3. Placement Status by Work Experience
4. Placement Status by MBA Specialization
5. SSC Percentage Distribution
6. HSC Percentage Distribution
7. Degree Percentage Distribution
8. MBA Percentage Distribution
9. Salary Distribution
10. Salary by Placement Status
11. Degree Percentage vs Salary
12. MBA Percentage vs Salary
13. Employability Test Score vs Salary
14. Academic Performance Comparison
15. Correlation Heatmap
